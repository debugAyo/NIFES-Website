NIFES FUTMinna — PICTURE DROP GUIDE
====================================

HOW TO USE
----------
1. Drop your pictures into the matching subfolder below.
2. When everything is in, zip the whole "images" folder and send it to the developer.
3. The developer adds the pictures to the website using the info below.

FOLDERS AND WHAT GOES WHERE
---------------------------

gallery/                 -> General fellowship gallery photos (gallery.html).
                           Name them: 1.jpg, 2.jpg, 3.jpg, ... in the order you
                           want them to appear. Categories are set on the site
                           (worship & prayer, bible study, community, outreach).

life26/                  -> Photos from the LIFE 2026 national conference
                           (gallery-life2026.html). Any naming is fine.

executives/gk/           -> G.K. executive officers. Name by role:
                           president, gen_sec, ass_gen_sec, treasurer,
                           sis_cord, ushering_cord, evangelism_cord,
                           prayer_cord, bible_cord, technical_cord,
                           music_director, academic_cord.

executives/bosso/        -> Bosso executive officers. Same naming as above.

events/                  -> Event photos (events.html) and general page photos
                           (home, about, etc.). Any naming is fine.

units/drama/             -> Drama unit photos.
units/bible-study/       -> Bible Study unit photos.
units/choir/             -> The Lord's Habitation Choir photos.
units/evangelism/        -> Evangelism unit photos.
units/follow-up/         -> Follow Up unit photos.
units/prayer/            -> Prayer unit photos.
units/publicity-media/   -> Publicity and Media unit photos.
units/technical/         -> Technical unit photos.
units/ushering/          -> Ushering unit photos.

TIPS
----
- Use JPG/PNG, keep file size reasonable (about 200KB - 1MB per photo).
- Give photos clear names (no spaces/special characters, e.g. sunday-worship.jpg).
- If a folder is empty, no photos are needed for it yet.
